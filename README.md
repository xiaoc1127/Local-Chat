## 简介
**本地聊天** 是一个用**C++**制作基于 ***Win32 / WinSock2*** 的本地双进程 **TCP** 聊天室。  
采用原生 API 实现，静态链接后无运行库依赖，支持 ***Windows XP 至 Windows 11**，适合局域网通信演示与教学实验

### 版本号格式
***vi.j.k(r|a|b)n***   
**i**: 大版本号，重大更新时+1  
**j**: 次版本号，更新新功能时+1  
**k**: 构造版本号，修复小bug时+1  
**(r|a|b)**: Release/Alpha/Beta  
**n**: 当前版本的重新发布次数
